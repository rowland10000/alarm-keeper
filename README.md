# 鬧鐘管家

會自己看行事曆的 iPhone 鬧鐘。

裝好之後，鬧鐘會自己判斷明天上班還是放假。國定假日、補班、颱風假都算進去；明天一早有行程，也會自動提早叫你。

iPhone 捷徑 · 免費

## 兩個捷徑

**鬧鐘管家**（主程式）
每晚自己判斷明天該開哪一個鬧鐘，清晨再查一次當天才宣布的颱風停班。

👉 https://www.icloud.com/shortcuts/2c640b7560b9416dae3f6a455d52f517

**排休排班**（輔助工具）
要請假或臨時調班時，選日期就會自動幫你在行事曆建好對應的行程。

👉 https://www.icloud.com/shortcuts/7812ce078f9f4684a7212d947ea7235f

> iPhone 捷徑只能透過 iCloud 連結安裝，沒辦法像一般程式那樣從這裡下載檔案。所以上面兩個連結才是真正的安裝入口，這個頁面放的是說明。

## 裝起來要做五件事

1. 在時鐘 App 建兩個鬧鐘，標籤分別打「上班」「休假」
2. 點上面兩個連結裝捷徑
3. 在捷徑 App 自己建兩條自動化（22:15 和 04:40，執行鬧鐘管家）
4. 回「所有捷徑」，把多出來的「22:15 鬧鐘管家」「04:40 鬧鐘管家」各點一次，跳出詢問選「允許」
5. 中午 12 點之後手動跑一次鬧鐘管家，詢問都選「永遠允許」

**第 3、4 步都不能跳過。** 自動化不會跟著捷徑裝進來，Apple 規定只能由手機主人自己建。而新版 iOS 會把自動化另存成捷徑，第一次執行時會問你要不要允許，半夜沒人按就會卡住，鬧鐘不會改。先在白天各點一次把它按掉。

每一步的畫面、三種班表模式、常見問題都在 [說明手冊](鬧鐘管家_捷徑設定手冊.pdf) 裡，含截圖。輪班或班表不固定的人一定要看。

## 平常怎麼用

國定假日、補班、颱風假都不用管。

要請假或臨時調班，在行事曆加一個行程，標題裡放 `#休` 或 `#班` 就會蓋過自動判斷。

放假資料來自人事行政總處的辦公日曆和停班停課公告。查不到的時候（沒網路、政府網站改版），它會退回「照上班鬧鐘響」。寧可放假多叫你一次，也不會害你遲到。

## 驗證到哪裡

**鬧鐘管家**：2026 年 10/23 到 10/26 這四天連假實測過。那四天剛好有三種不同的放假理由（10/23 薔琵颱風停班、10/25 光復節、10/26 補假），都有正確切到休假的鬧鐘。

但那是我自己這一台 iPhone。不同的 iOS 版本、不同的鬧鐘設定、不同的行事曆，我沒有辦法一一測過。**剛裝起來的頭幾天，請自己再確認一次鬧鐘有沒有開對**，不要第一天就完全交給它。

**排休排班**：這個我完全沒有實測過。功能寫出來了，邏輯我自己看過，但沒有真的跑過一輪完整的班表。要用的話請自己先在行事曆上確認它建出來的行程對不對。

## 幾件先說清楚的事

- 它只動你自己手機裡的鬧鐘和行事曆，不會把任何東西傳到別的地方
- 我沒有伺服器，所以這東西不會因為我哪天不維護就停掉
- 它會去抓政府網站的公開資料。如果對方改版，判斷可能會失準，這種時候它會退回照上班鬧鐘響
- 自己的班表還是要自己顧。這是個幫忙的工具，不是保證不會睡過頭的保險
